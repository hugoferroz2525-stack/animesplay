# AnimesPlay 1.5.0

[Baixar ZIP 1.5.0](https://github.com/hugoferroz2525-stack/animesplay/raw/refs/heads/main/plugin.video.animesplay-1.5.0.zip)

Atualize pelo ZIP, reinicie Kodi/Flixbox e abra novamente a obra/lista de episódios.

HLS nativo por padrão, validação de segmentos de vídeo/áudio, retomada adiada, paginação estável e diagnóstico recente. Recuperação entre servidores já agrupados funciona sem chave TMDB; configure sua chave/token para novos metadados.

119 testes automatizados passaram no ZIP extraído. Houve validação HTTP/HLS e decodificação externa, inclusive após seek. Kodi/MediaCodec Android não foi executado neste ambiente; serviços remotos ainda podem bloquear ou remover arquivos. [Resultados e limites](ATUALIZACAO-1.5.0.md).

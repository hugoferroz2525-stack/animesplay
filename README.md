# AnimesPlay 1.2.0

[Baixar o ZIP 1.2.0](https://github.com/hugoferroz2525-stack/animesplay/raw/refs/heads/main/plugin.video.animesplay-1.2.0.zip)

Instale no Kodi/Flixbox por **Add-ons → Instalar a partir de um arquivo ZIP** e reinicie o aplicativo.

Catálogo unificado de seis fontes, áudio antes dos servidores numerados, reprodução direta dos episódios e opções no contexto. Correção do player VIP de Pokémon, metadados individuais e imagens TMDB.

84 testes passaram a partir do ZIP extraído. Meti/Pokémon e AnimesDigital tiveram manifesto e primeiro segmento HLS confirmados. As demais fontes têm restrições descritas no [relatório](ATUALIZACAO-1.2.0.md). Não foi executado Kodi real neste ambiente.
